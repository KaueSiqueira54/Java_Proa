# ☕ Java_Proa

Repositório de estudos do curso **ProProfissão** do **Instituto Proa** — Turma 1 de Java.

Este repositório reúne os projetos, exercícios e experimentos desenvolvidos ao longo das aulas, cobrindo desde a sintaxe básica até tópicos avançados como Spring Framework e Programação Orientada a Objetos.

---

## 📚 Conteúdo

| Tópico | Descrição |
|---|---|
| 🔤 Sintaxe | Exercícios fundamentais de Java |
| 🧱 POO | Programação Orientada a Objetos |
| 🌱 Spring | Spring Framework e Spring Boot |
| 📁 Projetos | Mini projetos práticos das aulas |
